## 자동차 경주
---

### 구현해야 할 기능

### 자동차 이름 입력

- [x] 사용자는 쉼표(,)로 구분된 자동차 이름을 입력한다.
- [x] 이름은 5자 이하, 영문 대소문자만 허용한다.
- [x] 유효하지 않은 이름 입력 시 예외 발생 후 종료한다.

### 시도 횟수 입력

- [x] 사용자는 몇 번의 시도를 할지 입력한다.
- [x] 숫자가 아니거나 음수일 경우 예외 발생 후 종료한다.

### 경주 진행

- [x] 각 턴마다 모든 자동차가 동시에 전진 또는 멈춘다.
- [x] 랜덤 값이 4 이상이면 한 칸 전진한다.
- [x] 한 턴이 끝날 때마다 각 자동차의 위치를 출력한다.

### 우승자 결정

- [x] 모든 시도가 끝나면 가장 멀리 간 자동차가 우승한다.
- [x] 공동 우승자가 있을 수 있으며, 쉼표(,)로 구분해 출력한다.

### 출력

- [x] 각 턴마다 자동차 이름과 이동 거리를 함께 출력한다.
- [x] 마지막에 `최종 우승자 : pobi, jun` 형식으로 결과를 출력한다.
